# coffee-shop

Learning exercise: an Expo (React Native) coffee shop app with a home screen,
menu screen, and contact screen (`app/index.jsx`, `app/menu.jsx`, `app/contact.jsx`),
routed with `expo-router`.

## Stack
- Expo / React Native, TypeScript
- expo-router for file-based navigation

## Running locally
```bash
npm install
npx expo start
```

Then open in Expo Go, an Android/iOS simulator, or the web preview from the CLI output.
